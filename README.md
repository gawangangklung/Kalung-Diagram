# Kalung-Diagram

Aplikasi sederhana untuk menerjemahkan nomor Angklung ke semua nada dasar.

## Menjalankan aplikasi

```bash
python /home/runner/work/Kalung-Diagram/Kalung-Diagram/angklung_translator.py --source C "1 2 3 4 5 6 7"
```

Output akan menampilkan terjemahan ke 12 nada dasar.

### Contoh terjemahan ke satu nada dasar

```bash
python /home/runner/work/Kalung-Diagram/Kalung-Diagram/angklung_translator.py --source C --target D "1 2 3 4 5 6 7"
```
